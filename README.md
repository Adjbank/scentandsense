# Shinrin-Yoku @ ไร่เชิญตะวัน 🍃

เว็บแอป (PWA) สำหรับผู้ที่ต้องการบำบัดกายและใจด้วยการ "อาบป่า" (Shinrin-Yoku / 森林浴)
ที่ศูนย์วิปัสสนาสากลไร่เชิญตะวัน จ.เชียงราย — ถ่ายรูปต้นไม้แล้วรู้จักสายพันธุ์ ประวัติ
และเอกลักษณ์ด้านกลิ่นของพืชพรรณไทย สื่อสารได้ทั้งภาษาไทยและอังกฤษ

พัฒนาโดย บริษัท เซนท์ แอนด์ เซนส์ แลบอราทอรี่ จำกัด

## ความสามารถ

| หน้า | ทำอะไร |
|---|---|
| `/` | แดชบอร์ด mindfulness: ทักทายตามเวลา, การ์ดเริ่มนั่งสมาธิที่แนะนำตามช่วงวัน, ปุ่มลัด, เช็กอินอารมณ์, แผนวันนี้ (นับจากการใช้งานจริง), กลิ่นช่วยสมาธิประจำวัน |
| `/meditate` | รายการ session สมาธิ 8 แบบ แยกโหมด ตื่นรู้ / สงบ / หยั่งราก พร้อมแถบสัปดาห์และสถิติ (ครั้ง นาที วันติดกัน) |
| `/meditate/[id]` | ตัวจับเวลาวงกลม คำแนะนำตามช่วงเวลา เสียงประกอบ (เงียบ ระฆัง ลมป่า ฝน สังเคราะห์ด้วย Web Audio) และพืชคู่สมาธิพร้อมงานวิจัยของสารหอม |
| `/identify` | ถ่ายรูป/อัปโหลดภาพ → Claude vision ระบุพันธุ์พืช (สูงสุด 3 ตัวเลือก + ความมั่นใจ) → แสดงประวัติ เอกลักษณ์กลิ่น สารหอมหลัก (% + CAS) และแหล่งอ้างอิง |
| `/plants` | สารานุกรมพืช 67 ชนิดตามป้ายชื่อ "สมุนไพรในสวนลำไย" (ปลูก 26–28 ก.พ. 2569) เรียงตามหมายเลขป้าย ค้นหาด้วยชื่อหรือเลขป้าย กรองตามกลุ่มกลิ่น |
| `/plants/[slug]` | รายละเอียดพืชแต่ละชนิด สองภาษา |
| `/walk` | เส้นทางอาบป่า 5 สถานี พร้อมตัวจับเวลาหายใจ 4-7-8 |

## Mindfulness × กลิ่นพืช

- `src/data/mindful.ts` เก็บงานวิจัยระดับสารหอม 7 ฉบับ (1,8-cineole, linalool, α-pinene, citral, กลิ่นมะลิ, กลุ่มกระดังงา, phytoncide), เรื่องเล่ากลิ่นของพืช 12 ชนิดในแปลง และสคริปต์ session 8 แบบ
- งานวิจัยอ้างอิงในระดับ "สาร" ที่พบในพืชนั้น ไม่ได้อ้างว่าพืชในแปลงผ่านการทดลองโดยตรง
- ประวัติการนั่งและอารมณ์เก็บในเครื่องผู้ใช้ (localStorage) ไม่ส่งออกไปที่ใด
- ภาพประกอบใน `public/images/` สร้างด้วย Magnific

## เทคโนโลยี

- Next.js 16 (App Router, TypeScript, Tailwind CSS 4) — ติดตั้งเป็น PWA บนมือถือได้
- Anthropic SDK: `claude-opus-5-5` + structured output (zod) + server-side fallback
- ฐานข้อมูลพืชอยู่ในโค้ด: `src/data/plants/part1–4.ts` (รวมที่ `src/data/plants.ts`)
- ทดสอบด้วย Vitest (`tests/`)

## เริ่มใช้งาน

```bash
npm install
cp .env.example .env.local   # ใส่ ANTHROPIC_API_KEY
npm run dev                  # http://localhost:3000
```

ถ้าไม่ตั้ง `ANTHROPIC_API_KEY` หน้าอื่นยังใช้ได้ แต่ `/identify` จะแจ้งว่ายังไม่ได้ตั้งค่า (HTTP 503)

```bash
npm test        # vitest
npm run lint
npm run build
```

## Deploy บน Vercel

1. Import repo → Framework: Next.js (ตรวจจับอัตโนมัติ)
2. Environment Variables: `ANTHROPIC_API_KEY`
3. Route `/api/identify` ตั้ง `maxDuration = 60` วินาทีไว้แล้ว

## โครงสร้าง

```
src/app/            หน้าเว็บ + /api/identify

```

## การเพิ่มพืชใหม่

เพิ่ม object ในไฟล์ `src/data/plants/partN.ts` ตาม type `Plant` (`src/data/types.ts`)
พร้อม `signNo` ตามป้ายจริง แล้วรัน `npm test` — เทสต์จะตรวจว่า slug ไม่ซ้ำ
หมายเลขป้ายครบ 1–67 ไม่ซ้ำ ข้อความครบสองภาษา สัดส่วนสารหอมสมเหตุสมผล
และมีแหล่งอ้างอิงอย่างน้อย 1 รายการ (ถ้าเพิ่มชนิดที่ 68 ให้แก้ตัวเลขในเทสต์ด้วย)

## ข้อจำกัดที่ควรรู้

- รายชื่อ 67 ชนิดมาจากป้ายชื่อจริงในสวนลำไย ชื่อวิทยาศาสตร์ 7 รายการที่ชื่อพื้นบ้านใช้กับหลายชนิด
  (บัวสวรรค์ ประดู่ พญาดง เม่าหลวง ราชาวดี ว่านสาวหลง สังกรณีดอกม่วง) ติดธง `identityUncertain`
  ควรยืนยันจากต้นจริง
- พืชที่ไม่มีงานวิจัยองค์ประกอบสารระเหย จะระบุไว้ตรงๆ ว่ายังไม่พบรายงาน
- การระบุพืชด้วย AI อาจผิดพลาด ห้ามรับประทานหรือสัมผัสพืชที่ไม่รู้จักโดยอาศัยผลจากแอปเพียงอย่างเดียว
- สัดส่วนสารหอม (%) เป็นช่วงจากวรรณกรรม แปรตามพันธุ์ ฤดูกาล และวิธีสกัด
